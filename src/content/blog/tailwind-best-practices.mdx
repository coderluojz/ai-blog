# Tailwind CSS 最佳实践指南

Tailwind CSS 是一个实用优先的 CSS 框架，本文分享我在项目中的最佳实践。

## 项目配置

### 基础配置

```typescript
// tailwind.config.ts
import type { Config } from 'tailwindcss';

const config: Config = {
  content: ['./src/**/*.{astro,tsx,jsx}'],
  darkMode: 'class',
  theme: {
    extend: {
      fontFamily: {
        sans: ['Inter', 'sans-serif'],
      },
    },
  },
  plugins: [
    require('@tailwindcss/typography'),
  ],
};

export default config;
```

## 响应式设计

### 移动优先策略

```html
<!-- 默认移动，sm+ 平板，md+ 桌面 -->
<div class="w-full sm:w-1/2 md:w-1/3">
  响应式宽度
</div>
```

### 常用断点

| 断点 | 最小宽度 | 典型设备 |
|------|----------|----------|
| sm | 640px | 手机横屏 |
| md | 768px | 平板 |
| lg | 1024px | 小桌面 |
| xl | 1280px | 桌面 |
| 2xl | 1536px | 大桌面 |

## 暗色模式

```html
<div class="bg-white dark:bg-gray-900 text-gray-900 dark:text-white">
  支持暗色模式
</div>
```

## 组件模式

### 按钮组件

```html
<!-- 基础按钮 -->
<button class="px-4 py-2 rounded-lg bg-blue-500 text-white 
  hover:bg-blue-600 active:bg-blue-700 
  transition-colors duration-200 cursor-pointer">
  点击
</button>

<!-- 变体 -->
<button class="px-4 py-2 rounded-lg border border-gray-300 
  text-gray-700 hover:bg-gray-50 transition-colors cursor-pointer">
  次要按钮
</button>
```

### 卡片组件

```html
<div class="p-6 rounded-xl border border-gray-100 bg-white
  hover:shadow-lg hover:border-gray-200
  transition-all duration-300">
  卡片内容
</div>
```

## 排版

使用 `@tailwindcss/typography` 插件：

```html
<article class="prose prose-lg max-w-none">
  <h1>文章标题</h1>
  <p>文章内容...</p>
</article>
```

## 自定义工具类

```css
@layer utilities {
  .text-gradient {
    @apply bg-clip-text text-transparent 
      bg-gradient-to-r from-blue-500 to-purple-500;
  }

  .glass {
    @apply bg-white/70 backdrop-blur-lg;
  }
}
```

## 性能优化

1. **JIT 模式**：Tailwind 3.x 默认启用
2. **Purge 配置**：确保 content 路径正确
3. **避免动态类名**：使用完整类名而非拼接

## 总结

Tailwind CSS 极大地提高了开发效率，遵循这些最佳实践可以写出更清晰、更易维护的代码。
