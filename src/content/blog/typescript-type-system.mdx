# 深入理解 TypeScript 类型系统

TypeScript 的类型系统是其最强大的特性之一。本文将从基础到高级，全面介绍 TypeScript 的类型能力。

## 基础类型

```typescript
// 基础类型注解
const name: string = 'TypeScript';
const version: number = 5.0;
const isActive: boolean = true;

// 数组类型
const numbers: number[] = [1, 2, 3];
const names: Array<string> = ['Alice', 'Bob'];

// 元组
const pair: [string, number] = ['age', 25];
```

## 接口与类型别名

```typescript
// 接口
interface User {
  id: number;
  name: string;
  email: string;
  avatar?: string; // 可选属性
  readonly createdAt: Date; // 只读属性
}

// 类型别名
type ID = string | number;
type Callback<T> = (data: T) => void;
```

## 泛型

```typescript
// 泛型函数
function identity<T>(value: T): T {
  return value;
}

// 泛型接口
interface ApiResponse<T> {
  data: T;
  status: number;
  message: string;
}

// 泛型约束
function getProperty<T, K extends keyof T>(obj: T, key: K): T[K] {
  return obj[key];
}
```

## 条件类型

```typescript
// 条件类型
type IsString<T> = T extends string ? true : false;

// 分布式条件类型
type ToArray<T> = T extends any ? T[] : never;
type StrOrNumArray = ToArray<string | number>; // string[] | number[]

// infer 关键字
type ReturnType<T> = T extends (...args: any[]) => infer R ? R : never;
```

## 映射类型

```typescript
// 内置映射类型
type Readonly<T> = { readonly [K in keyof T]: T[K] };
type Partial<T> = { [K in keyof T]?: T[K] };
type Required<T> = { [K in keyof T]-?: T[K] };

// 自定义映射类型
type Nullable<T> = { [K in keyof T]: T[K] | null };
```

## 模板字面量类型

```typescript
type EventName = `on${Capitalize<'click' | 'focus' | 'blur'>}`;
// Result: 'onClick' | 'onFocus' | 'onBlur'

type CSSProperty = `${string}-${string}`;
```

## 实用类型技巧

```typescript
// 提取函数参数类型
type Params<T> = T extends (...args: infer P) => any ? P : never;

// 提取 Promise 返回类型
type UnwrapPromise<T> = T extends Promise<infer U> ? U : T;

// 深度只读
type DeepReadonly<T> = {
  readonly [K in keyof T]: T[K] extends object
    ? DeepReadonly<T[K]>
    : T[K];
};
```

## 最佳实践

1. **避免使用 `any`**：尽量使用 `unknown` 或具体类型
2. **启用严格模式**：`strict: true` 在 tsconfig 中
3. **利用类型推断**：让 TypeScript 自动推断简单类型
4. **使用类型守卫**：通过 `is` 关键字创建类型守卫

## 总结

TypeScript 的类型系统非常强大，掌握这些高级特性可以显著提升代码质量和开发体验。
